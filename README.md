# Minecraft Stars — Telegram Mini App

Адаптивний Mini App із космічним піксельним дизайном, прогресом-мечем, перевіркою підписок через Telegram Bot API та приватною адмінпанеллю.

## Передумови
- Node.js 20 або новіший
- Telegram-бот, створений через [@BotFather](https://t.me/BotFather)
- Бот має бути адміністратором кожного каналу, який потрібно перевіряти
- HTTPS-домен для реального Telegram Mini App

## Запуск локально
1. Розпакуйте проєкт і відкрийте папку в терміналі.
2. Виконайте `npm install`.
3. Скопіюйте `.env.example` у `.env`.
4. Заповніть `BOT_TOKEN`, `ADMIN_TELEGRAM_ID`, `MY_TELEGRAM_USERNAME`.
5. У `config/sponsors.js` змініть приклад на справжні канали: назву, URL і числовий `channelId` (зазвичай виглядає як `-100...`).
6. Виконайте `npm start` і відкрийте `http://localhost:3000`.

**Звичайний браузер без Telegram `initData` не може пройти автентифікацію API.** Це навмисно: сервер не довіряє Telegram ID, переданому клієнтом. Для перевірки функціональності відкривайте Mini App через Telegram. Не вимикайте перевірку підпису для зручності тестування.

## Налаштування Telegram
1. У Telegram відкрийте @BotFather і виконайте `/newbot`; збережіть токен лише в `.env` на сервері.
2. Додайте бота адміністратором кожного каналу. Він повинен мати право переглядати учасників/виконувати `getChatMember`; адміністративні права зазвичай потрібні для гарантованої перевірки інших користувачів.
3. Отримайте числовий chat ID каналу надійним способом і внесіть його в `config/sponsors.js` або адмінпанель. Не покладайтеся на назву каналу як на ідентифікатор.
4. `ADMIN_TELEGRAM_ID` — ваш числовий Telegram ID. Вкажіть його в `.env`. Адмінпанель доступна за `/admin`, але всі API-запити додатково перевіряють підписані дані Telegram та ID на сервері.
5. `MY_TELEGRAM_USERNAME` — ваш username без `@`. Якщо не налаштований, фінальна кнопка покаже помилку замість вигаданого посилання.
6. Розмістіть сайт на HTTPS-хостингу. У налаштуваннях бота через BotFather налаштуйте Mini App / Web App URL на адресу сайту. Назви пунктів BotFather можуть змінюватися.

## Важливі деталі безпеки
- Ніколи не комітьте `.env` і не надсилайте токен бота в чатах.
- Сервер перевіряє `initData` за HMAC, включно з терміном дії; не приймає Telegram ID із довільного JSON як автентифікацію.
- Прогрес обчислюється на сервері за останніми результатами перевірок; наступна перевірка виявить відписку.
- Якщо Telegram API повертає помилку, статус показується як помилка перевірки, а не успіх.
- Дані зберігаються в SQLite у файлі з `DATABASE_PATH`. На хостингу переконайтеся, що диск постійний і має резервні копії.
- Перед публічним запуском рекомендується додати політику конфіденційності, обмеження доступу до резервних копій, моніторинг і протестувати конфігурацію каналів.

## Файли
- `public/index.html`, `public/style.css`, `public/app.js` — користувацький Mini App.
- `public/admin/index.html`, `public/admin/admin.js` — адміністративний інтерфейс.
- `server.js` — API, перевірка Telegram `initData`, Bot API та адмін-авторизація.
- `config/sponsors.js` — початкові спонсори.
- `.env.example` — шаблон серверних секретів.
- `data/` — автоматично створювана директорія бази даних.
